SWE334 Интернэт програмчлал · Бие даалт 2

## Сайтын тухай

Өөрийгөө, ур чадвар болон бүтээлүүдээ танилцуулсан хувийн портфолио вэбсайт. Загвар нь **glassmorphism** (бүдэг шилэн хавтан, ард нь хөдөлдөг өнгөт бөмбөлгүүд).

- **Миний тухай (нүүр):** монгол бичгээр бичсэн нэр, нэр, чиглэл, товч танилцуулга, Download CV, оосортой даалгаатай ID карт (чирж шидэхэд дүүжин шиг найгана)
- **Батламж:** сайн дурын ажил, эрдэм шинжилгээний 9 батламж; төрлөөр шүүх, зургийг томруулж харах
- **Мэргэжлийн ур чадвар:** лого, нэр, ангилалтай картууд; ангиллаар шүүх, эхний 8-ыг харуулж «Бүгдийг харах» товчоор дэлгэнэ
- **Бүтээлүүд:** жижиг галерейн өрөө (CSS clip-path хана, шатрын хээтэй шал); бүтээлүүд хананд зураг шиг өлгөөтэй; doodle дүр зурагнуудын өмнүүр алхаж бүтээл бүрийн өмнө зогсоно (автомат аялал), дарахад доор нь музейн хаяг шиг тайлбар гарна; буланд зогсох миний doodle дүр дээр дарахад «Надтай ярилц» чат нээгдэж, бэлэн асуултаас сонгох эсвэл бичиж асууна (хариултууд `data/chat.js`-д, түлхүүр үгээр тааруулна)
- **Холбоо барих:** имэйл, GitHub, сошиал холбоосууд, имэйл хуулах товч
- **Цайвар / бараан горим** (сонголтыг localStorage-д хадгална)
- Гарч ирэх анимэйшн (`IntersectionObserver`), утсанд зориулсан цэс

## Технологи

| Хэрэгсэл | Юунд |
|---|---|
| React 18 + Vite | UI, компонент |

## Локал дээр ажиллуулах

```bash
npm install
npm run dev
```

## Эх сурвалж

- ID картын санаа: React Bits «Lanyard» (Three.js + Rapier)-аас санаа авч, физикийн сангүйгээр энгийн дүүжингийн тэгшитгэлээр дахин бичсэн; hero бүтцийн санаа: shadcn studio «Hero Section 44»
- Загварын санаа: 21st.dev дээрх «Glassmorphism Portfolio Block» (shadcn/ui, Tailwind, framer-motion)-ийг энгийн CSS, React-аар дахин бичсэн
- Icon: Lucide (ISC) загвараар SVG
- Лого: Devicon (devicon.dev, MIT)
- Фонт: Unbounded, Manrope, JetBrains Mono — Google Fonts (OFL)
- AI хэрэгсэл (Claude)-ийг кодын туслахаар ашигласан.
