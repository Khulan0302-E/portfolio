## Сайтын тухай

Үндсэн боломжууд

1. Миний тухай (Home)

Нэрийг уламжлалт монгол бичгээр болон кирилл бичгээр харуулах.

Мэргэжил, чиглэл, өөрийн тухай товч танилцуулга байрлуулах.

CV файлыг татаж авах боломжтой Download CV товчтой байх.

Оосортой, ID карт хэлбэрийн интерактив танилцуулга нэмэх.

ID картыг хулганаар чирж, шидэхэд физикийн хөдөлгөөнийг дуурайлган дүүжин мэт найгах анимэйшнтэй байх.

2. Батламж, гэрчилгээ (Certificates)

Сайн дурын ажил болон эрдэм шинжилгээний чиглэлээр авсан нийт 9 батламж, гэрчилгээг харуулах.

Батламжуудыг төрлөөр нь ангилан шүүх боломжтой байх.

Батламжийн зургийг сонгоход томруулж, дэлгэрэнгүй харах боломжтой байх.

3. Мэргэжлийн ур чадвар (Skills)

Ур чадвар бүрийг лого, нэр, ангилал бүхий картаар дүрслэх.

Ур чадваруудыг ангиллаар нь шүүх боломжтой байх.

Эхний ээлжид 8 ур чадварыг харуулах.

Бүгдийг харах (View All) товчийг дарахад үлдсэн ур чадварууд дэлгэгддэг байх.

4. Бүтээлүүд (Projects / Gallery)

Бүтээлүүдийг энгийн жагсаалт хэлбэрээр бус, жижиг хэмжээний интерактив музейн галерей өрөө хэлбэрээр танилцуулна.

Өрөөний ханыг CSS clip-path ашиглан дүрслэх.

Шалыг шатрын хээтэй загвараар хийх.

Бүтээл бүрийг хананд өлгөсөн зураг мэт байрлуулах.

Doodle дүрүүд галерейн дотор алхаж, бүтээл бүрийн өмнө ээлжлэн зогсох автомат аяллын анимэйшнтэй байх.

Бүтээл дээр дарахад тухайн бүтээлийн нэр, тайлбар болон мэдээлэл музейн танилцуулгын самбар шиг дэлгэгддэг байх.

Галерейн буланд байрлах өөрийн Doodle дүр дээр дарахад "Надтай ярилц" чат цонх нээгдэх.

Чат хэсэгт хэрэглэгч бэлэн асуултуудаас сонгох эсвэл өөрийн асуултыг бичиж илгээх боломжтой байх.

Чатын асуулт, хариултуудыг data/chat.js файлд хадгалах бөгөөд хэрэглэгчийн бичсэн асуултыг түлхүүр үгээр нь тааруулан тохирох хариултыг харуулах.

5. Холбоо барих (Contact)

Имэйл хаяг.

GitHub профайл.

Сошиал медиа холбоосууд.

Имэйл хаягийг нэг товшилтоор хуулах боломжтой товч.

Холбоо барих мэдээллийг ойлгомжтой, цэгцтэй байдлаар харуулах.

6. Цайвар болон бараан горим (Theme)

Light Mode болон Dark Mode сонголттой байх.

Хэрэглэгч горимоо солиход вэбсайтын өнгө, дизайн тохирох байдлаар өөрчлөгдөх.

Сонгосон горимыг localStorage ашиглан хадгалах.

Дараагийн удаа вэбсайтад нэвтрэхэд өмнөх сонголтыг автоматаар сэргээх.

Технологи

| Хэрэгсэл | Юунд |
|---|---|
| React 18 + Vite | UI, компонент |
| CSS (custom properties, media query) | Загвар, горим, responsive |
| Vercel | Байршуулалт |


Бүтэц

```
src/
  App.jsx                үндсэн бүтэц, горим солих
  components/
    Navbar.jsx           хөвөгч шилэн цэс, утасны цэс, горимын товч
    Hero.jsx             нүүр хэсэг
    IdBadge.jsx          даалгаатай ID карт (дүүжингийн физик, чирэх)
public/Khulan_CV.jpg     «Download CV» товчоор татагдах CV зураг
    Section.jsx          шилэн хавтантай хэсэг + анимэйшн
    Certificates.jsx     батламжууд, шүүлтүүр, lightbox
    SocialLinks.jsx      сошиал холбоосын жагсаалт
    Icon.jsx             SVG icon-ууд
    Skills.jsx           мэргэжлийн ур чадварын картууд
    Projects.jsx         бүтээлүүдийн галерей, автомат аялал
    Walker.jsx           алхдаг doodle дүр (SVG + CSS анимэйшн)
    Me.jsx               буланд зогсох миний doodle дүр
    Chat.jsx             «Надтай ярилц» чат
    Contact.jsx          холбоо барих
  hooks/
    useReveal.js         дэлгэцэнд орж ирэхийг илрүүлэх
  data/
    certificates.js      батламжуудын жагсаалт
    chat.js              чатын асуулт, хариулт, түлхүүр үгс
    profile.js           ур чадвар (лого), холбоосууд
    projects.js          бүтээлүүдийн жагсаалт
```

Локал дээр ажиллуулах

```bash
npm install
npm run dev
```
